# Glossaire Ancrage

| Terme | Sens |
|---|---|
| Prospect | Personne ou organisation demandant un audit ou une démonstration. |
| Établissement / Business | Activité locale analysée ; distincte de la personne de contact. |
| MinimalRequest | Demande initiale contenant identité et ville, avant constitution du dossier. |
| GooglePlacesSelection | Identité choisie via Google Places ; distincte d’une observation GMB corroborée. |
| EstablishmentMatch | Rapprochement explicable entre demande, établissement et sources ; aucune sélection silencieuse en cas de conflit. |
| Dossier | Informations et actifs autorisés d’un établissement pour l’audit ou la génération. |
| AuditRun | Exécution bornée d’un audit avec modules, état, budget et preuves. |
| EvidenceSnapshot | Preuve datée et hashée rattachée à une source, une collecte et une règle. |
| SEOFinding | Observation ou anomalie SEO reliée aux pages et preuves concernées. |
| AuditPacket | Snapshot versionné de l’audit, de ses preuves, coûts, limites et artefacts ; les vues en sont des projections. |
| GMBAuditReport | Rapport intermédiaire de présence locale, sans preuve implicite de propriété de fiche. |
| SEOReport | Rapport de l’analyse du site et de sa visibilité, avec priorités et limites. |
| DemoRequest / Préparation | Demande de site créée après rapport final et e-mail ; elle peut être incomplète. |
| PreparationDraft | Préremplissage sourcé issu de l’audit, à confirmer avant génération. |
| SiteSpec | Description validée du site et des actifs utilisés par le pipeline. |
| Run / PipelineRun | Exécution versionnée d’étapes avec dépendances, checkpoints et événements. |
| ConfigurationDraft | Brouillon sans effet sur les exécutions avant activation. |
| ConfigurationSnapshot | Versions et hashes figés pour une exécution. |
| Provider | Service externe appelé derrière un adaptateur et une politique de coût. |
| CostLedger | Journal des autorisations, réservations, dépenses et annulations d’un run. |
| QualityGate | Contrôle produisant PASS, WARN ou BLOCK avec une preuve. |
| AcceptanceReport | Résultat des contrôles du site et décision attendue de l’opérateur. |
| Demo | Aperçu temporaire présenté après validation opérateur ; distinct d’un site publié. |
| Cockpit | Interface privée d’observation, configuration et validation. |
| Control Plane | Autorité sur les états, transitions, autorisations, budgets et provenance. |
| Agent | Contribution spécialisée à une étape ; ne décide pas seul de l’état métier. |
| Customer | Établissement ayant validé un achat ; distinct d’un prospect. |
| ProductionSite | Site durable publié après achat et validation ; distinct d’une simulation. |
