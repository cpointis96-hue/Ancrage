# Tickets locaux

- Un sujet par `.scratch/<sujet>/` ; exigences dans `spec.md`.
- Une tâche par `issues/NN-description.md` ; `Status: open | claimed | resolved`.
- Dépendances : `Blocked by: NN, NN` ; traiter les tâches ouvertes sans dépendance non résolue.
- Lire uniquement le ticket concerné. À résolution, consigner le résultat et sa vérification dans ce ticket.
- Actualiser la référence courante ; ne pas accumuler de copies ou d’archives.
