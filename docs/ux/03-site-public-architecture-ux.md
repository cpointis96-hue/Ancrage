# Architecture UX du site public

## Ton

Calme, clair, humain et précis. Le site explique ce qui se passe sans promettre ce que le système ne peut pas garantir.

## Page d'accueil

La première vue doit répondre à trois questions :

1. qu'est-ce que j'obtiens ?
2. combien dois-je faire maintenant ?
3. que se passe-t-il ensuite ?

Une seule action principale démarre le parcours. Les détails techniques, providers et coûts internes restent absents du site public.

## Parcours d'entrée

### Étape 1 — Nom et ville

Deux informations seulement. La ville est choisie dans une liste structurée. Aucun formulaire long sur la première vue.

### Étape 2 — Identification

- une correspondance forte : confirmation légère ;
- plusieurs correspondances : choix comparatif de 2 ou 3 candidats ;
- aucune correspondance fiable : adresse uniquement, puis aperçu local.

### Étape 3 — Complétude

Le système affiche ce qu'il a trouvé et demande uniquement les champs critiques manquants. Les photos obligatoires sont expliquées par leur utilité, sans jargon.

### Étape 4 — Valeur progressive

L'audit GMB apparaît dès qu'il est prêt. L'audit SEO de base peut avoir démarré en parallèle et l'audit SEO général reste visible comme progression réelle. Un rapport partiel est utile mais clairement marqué.

### Étape 5 — Préparer mon site

Le clic lance une courte préparation honnête puis demande l'e-mail. L'écran affiche ensuite les éléments manquants, notamment les photos et les informations métier, par petites étapes. Un e-mail valide enregistre la préparation, mais aucune génération réelle ne commence avant la checklist complète.

## Rapport public

Ordre de lecture :

1. résumé ;
2. cinq priorités ;
3. preuves et exemples ;
4. périmètre ;
5. limites ;
6. bouton discret « Télécharger le rapport PDF » toujours accessible pendant le défilement.

Le bouton PDF ne doit pas recouvrir le CTA principal, le contenu ou les champs. Il utilise une icône reconnaissable et un libellé accessible.

## Mascotte

La mascotte sert uniquement à :

- expliquer un terme ;
- guider une première étape ;
- confirmer une action ;
- rendre une attente ou une erreur moins froide.

Elle ne remplace jamais un libellé, ne boucle pas en animation et ne porte aucune promesse commerciale. Le mode réduit des animations doit être respecté.

## Mobile

- une colonne par défaut ;
- CTA principal atteignable sans chercher ;
- aucun tableau large obligatoire ;
- champs regroupés par petites étapes ;
- clavier mobile ne masquant jamais le champ actif ;
- téléchargement PDF accessible sans geste précis ;
- texte lisible à 200 % sans contenu coupé.
