# Mode démo local non commercial

Ce mode est volontairement utilisé pour tester le produit avant sa commercialisation.

Dans la démo :

- `Préparer mon site` est accessible après le rapport final sans paiement ;
- un e-mail valide reste obligatoire pour créer ou reprendre la `DemoRequest` ;
- le dossier métier reste obligatoire : identité, adresse si nécessaire, horaires, menu, prix, coordonnées, langue et informations réellement fournies ;
- les cinq catégories de photos restent obligatoires, avec des droits connus ;
- la génération, la QA, la validation opérateur et la démo privée restent obligatoires ;
- aucun paiement, `Account`, domaine, publication ou document juridique n’est demandé.

Ce mode ne supprime pas ces éléments du produit final. Il désactive uniquement les gates commerciales et juridiques réservées à la fin du projet. Les specs de paiement, de domaine, de publication et de conformité restent conservées comme cible ultérieure.

Le résultat est une démo de test opérateur, non une offre commercialisable et non une preuve de conformité juridique ou de production.
