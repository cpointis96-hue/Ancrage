# Outils de vérification
Périmètre : scripts de ce dossier.
Entrée : code, options et fixtures ; sortie : diagnostics ou artefacts dans outputs/ (ignoré).
check.mjs vérifie syntaxe, JSON et liens locaux. preview-audits.mjs utilise uniquement des fixtures. verify-audit-live.mjs exige une commande explicite et un budget borné ; ne pas le lancer pour vérifier un nettoyage.
Ne pas conserver de scripts datés redondants, secrets ou sorties générées dans Git.
